# 交互对抗性审查（2026-08-09）

## 复现与根因

1. 梅花与帮助图标在灰度链接中消失：入口脚本带上了 `preview`，静态图片没有，因而被路由到不含新资源的稳定版本并返回 404。
2. 学生提交复述后出现大块空白：页面把训练区历史最大高度永久写进 `min-height`，阶段内容变短后仍保留旧高度；同时新反馈定位到顶部，进一步放大了错位感。
3. 追问区与主答案区同时展示两个大输入框，并重复出现换讲法入口。
4. 图标依赖 CSS 中的静态资源地址，和梅花存在同样的灰度路由风险。

## 修复

- 梅花和三枚 Lucide 图标都显式跟随灰度参数；图标改为真实图片元素，不再依赖 CSS mask 的嵌套请求。
- 页面高度只在请求加载期间临时锁定；反馈生成后立即解除，并把最新私教反馈定位在视野中间。
- 删除下方“我还是没听懂，换种讲法”；保留教学区唯一的“讲明白（解释＋例子）”。
- 追问改为右下角“问私教”浮动入口，展开后才显示追问面板；打开、关闭和追问都不清空主答案草稿。
